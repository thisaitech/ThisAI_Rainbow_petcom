# 🐠 Rainbow Aqua and Pets

Premium Cloned Aquarium Fish & Exotic Pets E-commerce Website

**Powered by ThisAI Technologies**

## Features

- 🎨 **Modern Design** - Beautiful ocean-themed UI with dark mode support
- 📱 **Fully Responsive** - Mobile-first design (320px to 4K)
- 🐟 **Animated Loading Screen** - Stunning fish animation with bubbles
- 🛒 **Complete E-commerce** - Cart, checkout, account management
- 🔍 **Advanced Filters** - Shop with category, price, and stock filters
- 💳 **Payments** - Cash on Delivery now, Razorpay pending backend verification setup

- 🎯 **SEO Optimized** - Full meta tags and Open Graph support
- ⚡ **PWA Ready** - Installable on mobile devices

## Tech Stack

- **Framework:** Next.js 14.2+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Backend:** Firebase Authentication + Firestore + Cloud Storage
- **Components:** shadcn/ui + Radix UI
- **State:** Zustand
- **Animation:** Framer Motion
- **Carousel:** Swiper
- **Icons:** Lucide React

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/your-repo/aquapet-haven.git
cd aquapet-haven
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_FIREBASE_API_KEY=your-firebase-api-key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your-project-id.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your-project-id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your-project-id.firebasestorage.app
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your-messaging-sender-id
NEXT_PUBLIC_FIREBASE_APP_ID=your-firebase-app-id
NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID=your-measurement-id
```
